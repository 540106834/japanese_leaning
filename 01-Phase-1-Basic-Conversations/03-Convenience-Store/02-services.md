# 03-Convenience-Store｜services 便利店便民服务话术（Phase1 生存会话）

## 一、阶段学习说明（严格适配 Phase1 方法论）

✅ **本章节学习规则：只模仿、不分析、不记语法、不拆单词**

✅ **学习目标**：全覆盖日本便利店增值服务场景，包含餐具、热水、打印复印、缴费、邮寄、年龄确认、便民工具等，实现服务类需求无障碍沟通

✅ **核心逻辑**：解决「想索要服务不会说、听不懂店员确认、不敢开口求助便民服务」的刚需问题，所有句型语法原理全部后置 Phase2

❌ 无需掌握：助词变形、敬语层级、句式结构、单词拆解规则

## 二、基础便民服务｜餐具/热水/打包

**使用场景**：购买熟食、饮品、便当，索要基础配套服务

### 1. 麻烦给我筷子/餐具

**お箸お願いします**

罗马音：ohashi onegaishimasu

读音：哦哈西 哦内该西马斯

释义：麻烦给我筷子

场景：购买便当、饭团、熟食，需要餐具就餐

### 2. 麻烦给我勺子

**スプーンお願いします**

罗马音：supuun onegaishimasu

读音：斯普恩 哦内该西马斯

释义：麻烦给我勺子

场景：甜品、汤品、盖饭、酸奶专用

### 3. 麻烦给我叉子

**フォークお願いします**

罗马音：fooku onegaishimasu

读音：福库 哦内该西马斯

释义：麻烦给我叉子

场景：意面、沙拉、西式简餐专用

### 4. 麻烦给我热水

**お湯をお願いします**

罗马音：oyu o onegaishimasu

读音：哦优 哦内该西马斯

释义：麻烦给我热水

场景：冲泡泡面、茶饮、速食，便利店免费热水服务

### 5. 不需要餐具

**お箸は大丈夫です**

罗马音：ohashi wa daijoubu desu

读音：哦哈西哇 戴舅布戴斯

释义：不用筷子/餐具没关系

场景：无需配套餐具，礼貌回绝店员默认提供

## 六、年龄确认&烟酒专用应答｜高频必用

**核心说明**：购买烟酒、酒类饮料，店员必触发年龄确认弹窗，零基础万能应答

### 1. 我已满20岁（万能确认）

罗马音：nijussai ijou desu

读音：尼朱赛 一乔 戴斯

释义：我20岁以上

### 2. 麻烦确认屏幕

**画面タッチお願いします**

罗马音：gamen tatchi onegaishimasu

读音：嘎门 塔奇 哦内该西马斯

释义：麻烦点击屏幕确认（配合店员操作）

## 七、便利店服务黄金连招｜无脑复用

**连招1：便当就餐完整连招（最高频）**

お会計お願いします、温めてください、お箸お願いします

罗马音：okaikei onegaishimasu, atatamete kudasai, ohashi onegaishimasu

释义：麻烦结账，请帮我加热，麻烦给我筷子

**连招2：无餐具极简连招**

お会計お願いします、お箸は大丈夫です

罗马音：okaikei onegaishimasu, ohashi wa daijoubu desu

释义：麻烦结账，不用筷子

**连招3：文件复印办公连招**

コピーお願いします、白黒でお願いします

罗马音：kopii onegaishimasu, shiroguro de onegaishimasu

释义：麻烦帮我复印，要黑白的

**连招4：烟酒购买保命连招**

20歳以上です、お会計お願いします

罗马音：nijussai ijou desu, okaikei onegaishimasu

释义：我已满20岁，麻烦结账

**连招5：邮寄快递标准连招**

すみません、荷物を送りたいです、教えてください

罗马音：sumimasen, nimotsu o okuritai desu, oshiete kudasai

释义：不好意思，我想寄快递，麻烦告诉我怎么操作

## 八、场景区分口诀（Phase1 只记场景不记语法）

1. **吃便当熟食** → お箸お願いします

2. **不需要餐具** → お箸は大丈夫です

3. **打印复印文件** → コピー / プリント お願いします

4. **寄快递/信件** → 荷物を送りたいです / 切手をお願いします

5. **缴费充值** → 支払いお願いします

6. **购买烟酒** → 20歳以上です

## 九、Phase1 专属训练方案（极简落地）

1. 不拆解语法、不研究句式变形、不深究单词逻辑，只绑定服务场景跟读复用

2. 优先吃透核心四句：**お箸お願いします / コピーお願いします / 支払いお願いします / 20歳以上です**

3. 熟练五套黄金连招，全覆盖就餐、办公、邮寄、缴费、烟酒购买全服务场景

4. 核心目标：解决便利店各类增值服务不会开口、沟通卡顿、应答失误的问题

## 十、禁止误区（严格贴合体系原则）

❌ 不要拆解「をお願いします」通用句式语法

❌ 不要区分各类服务名词的词性与变形规则

❌ 不要孤立背诵单句，必须场景成套记忆、成套使用

✅ Phase1 核心：**先搞定全部生活服务场景，后学习底层语法原理**
