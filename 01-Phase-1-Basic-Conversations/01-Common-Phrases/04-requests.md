# 01-Common-Phrases｜requests 请求求助话术（Phase1 生存会话）

## 一、阶段学习说明（严格适配 Phase1 方法论）

✅ **本章节学习规则：只模仿、不分析、不记语法、不拆单词**

✅**学习目标**：掌握外出刚需求助、请求帮忙、索要服务的完整话术，遇事敢开口、会求助

✅ **核心逻辑**：先解决「不敢求人、不会提需求、沟通卡顿」的生存问题，所有句型原理后置 Phase2

❌ 无需掌握：动词变形、助词逻辑、句式结构、敬语规则

## 二、万能前置铺垫｜所有请求通用开头

**使用场景**：问路、找店员、请人帮忙、索要服务，所有求助场景前置礼貌开场

**すみません**

罗马音：sumimasen

读音：斯米马森

释义：你好/不好意思/打扰一下

核心用法：日本求助万能开头，先吸引对方注意，再提出请求，礼貌不突兀

## 三、基础请求句式｜零基础必背万能句

### 1. 请帮我一下 / 麻烦你（通用刚需）

**手伝ってください**

罗马音：tetsudatte kudasai

读音：次茨达贴 库达赛

场景：拎东西、找路、操作设备、遇到困难需要路人/店员协助

### 2. 可以帮我吗？（委婉轻声求助）

**手伝ってもいいですか**

罗马音：tetsudatte mo ii desu ka

读音：次茨达贴莫 一戴斯卡

场景：不确定对方是否方便，礼貌询问能否帮忙，态度更谦和

### 3. 麻烦请再说一遍（听不懂通用）

**もう一度お願いします**

罗马音：mou ichido onegaishimasu

读音：莫一奇多 哦内该西马斯

场景：对方语速太快、没听清、听不懂内容，请求重复说明

### 4. 麻烦请慢一点（适配日语听力薄弱）

**ゆっくりお願いします**

罗马音：yukkuri onegaishimasu

读音：优库里 哦内该西马斯

场景：对方说话语速过快，适配零基础听力短板，高频实用

## 四、场景专属请求｜外出生存高频句式

### 1. 购物/点餐请求

**これをお願いします**

罗马音：kore o onegaishimasu

读音：阔类哦 哦内该西马斯

释义：麻烦给我这个

场景：便利店、超市、餐厅、柜台点单、选购商品，万能购物请求

### 2. 询问信息请求

**教えてください**

罗马音：oshiete kudasai

读音：哦西诶贴 库达赛

释义：麻烦告诉我一下

场景：问路、问营业时间、问费用、问办理流程

### 3. 临时小额求助

**ちょっと手伝って**

罗马音：chotto tetsudatte

读音：乔托 次茨达贴

场景：熟人、同龄人、身边人小额帮忙，非正式轻松请求

## 五、黄金请求连招｜无脑直接复用

**连招1：标准求助完整句式（90%场景通用）**

すみません、手伝ってください（sumimasen, tetsudatte kudasai）

释义：打扰一下，麻烦帮我一下

**连招2：听不懂急救连招（零基础保命）**

すみません、ゆっくりお願いします、もう一度お願いします（sumimasen, yukkuri onegaishimasu, mou ichido onegaishimasu）

释义：不好意思，麻烦慢一点，请再说一遍

**连招3：购物点餐万能连招**

これをお願いします、ありがとうございます（kore o onegaishimasu, arigatou gozaimasu）

释义：麻烦给我这个，谢谢

**连招4：问路咨询标准连招**

すみません、教えてください（sumimasen, oshiete kudasai）

释义：打扰一下，麻烦告诉我一下

## 六、场景区分口诀（Phase1 只记用法）

1. **开口求助开场** → すみません

2. **购物、点单、索要物品** → これをお願いします

3. **需要人工帮忙、协助做事** → 手伝ってください

4. **问路、问规则、问信息** → 教えてください

5. **听不懂、跟不上语速** → ゆっくりお願いします / もう一度お願いします

## 七、Phase1 专属训练方案（极简落地）

1. 不拆解语法、不背诵单词、不研究变形，只记忆「场景+发音+用法」

2. 优先吃透 **すみません + これをお願いします** 两大核心万能句

3. 整套连招每日跟读循环，形成条件反射，遇到问题直接脱口而出

4. 核心目标：彻底解决出国在外不敢求助、不会提需求、沟通卡顿的生存难题
